# POL-SRV-001 — Employee Service Requests, Service Levels and Escalation

> SYNTHETIC MOCK POLICY for prototype testing. Not a real Emirates policy.

## 1. Raising a request
1.1 Raise requests through the HR service portal, the IT Service Desk, the Facilities portal or the Employee Journey Companion.
1.2 A complete request includes: what you need, by when, any reference numbers and any documents. Incomplete requests may be set to "Pending information".

## 2. Service levels (working days)

| Category | Request type | Service level |
|---|---|---|
| IT | Equipment issue | 2 |
| IT | System access | 1 |
| IT | Loan device | 0.5 |
| Facilities | Accommodation | 3 |
| Facilities | Maintenance (non-urgent) | 3 |
| Government Relations (PRO) | Visa, medical or Emirates ID step | 5 |
| HR Operations | Letters and transfer documents | 3 |
| HR Operations | General HR query | 3 |
| Payroll | Allowance payment | 5 |
| Learning & Development | Training booking | 3 |
| Security | Staff ID or pass | 2 |
| Global Mobility | Relocation or work permit query | 3 |

## 3. Escalation
3.1 Level 1: a request exceeding its service level is flagged to the owner team lead.
3.2 Level 2: a request exceeding 2 times its service level, or blocking a journey step due within 7 days, is escalated to the owner team's manager and the employee's HRBP.
3.3 Every escalation names a human owner who is accountable for the next action and the date of the next update.
3.4 The employee is told who owns their case and when they will next hear back.

## 4. Pending information
4.1 If a request is set to "Pending information", the owner team must say exactly what is missing.
4.2 If a request stays "Pending information" for more than 3 working days, the owner team must contact the employee directly.

## 5. Complaints
5.1 If you are unhappy with how a request was handled, contact your HRBP. This is separate from the formal grievance procedure.
